# 页面导航树与模块语义归属正交

> 后续边界：自动跨页遍历已由 [`2026-09-01-low-confidence-candidate-no-auto-navigation.md`](2026-09-01-low-confidence-candidate-no-auto-navigation.md) 替代；本决策的页面树、当前页候选和人工纠错路径继续有效。

## 原因

左侧承担页面映射，但当前直接显示 Spec 的“模块 → 页面 → 节点”语义结构。非 DOM 约束已经移到右侧后，模块继续作为映射树根只会遮挡用户真实经过的页面导航关系。现有 JSON 又把 pages 嵌在 module 内，无法可靠表达一个页面承载多个模块，也没有显式页面父子关系。

## 决定

- 保持三层事实边界：Markdown Spec 只表达功能决定；JSON 页面元数据表达功能出现位置；`spec-map.json` 表达节点与具体 DOM 的人工确认关系。页面树不反向决定正文结构、节点拆分或表述方式。
- 新投影在 bundle 顶层使用全局 `pages[]`；模块继续保存节点和非 DOM 约束，节点通过 `pageId` 引用全局页面。
- `pages` 和 `pageId` 只在页面证据足够时写入；没有页面证据时允许空页面投影和空 `pageId`，不得为满足页面树编造页面。
- 页面增加可选 `parentPageId`。只有该字段形成合法、无环引用时才展示导航层级；没有该字段的页面作为根页面平铺。
- 旧版 `module.pages` 保持兼容读取，且全部视为事实明确的页面分组；没有显式 `parentPageId` 时不推断父子关系。
- 左侧是稳定的 Spec 任务导航，不是中间页面的状态镜像。左侧页面或节点点击可以单向驱动中间导航与定位；用户在中间页面内自由浏览时，不得反向改变左侧展开、滚动或当前选中节点。模块仅作为筛选、节点标签、搜索证据和右侧公共约束归属。
- 同一功能 DOM 最多只能识别一个逻辑当前页。新版全局 pages 和旧版 module.pages 均跨模块统一比较；兼容路径不得为每个模块各选一个当前页。不同 pageId 同分或证据不足时不标记当前页。
- 页面行只显示页面名和一个总进度，不标记或自动展开“当前页”。点击收起只改变左侧；点击展开时先保存等待中的 Map，再按显式 hash/query `routeHints` 导航；没有明确路由时只打开该页面绑定清单，不伪造导航。
- `invalid / ambiguous / drifted` 继续作为底层映射状态，对用户统一称为“需复核”；筛选仅在数量大于零时出现。“需复核”不表示 PM 尚未阅读。
- 单击未映射 Spec 时，当前 DOM 只要存在真实文本、语义词或稳定属性重合的候选，就立即定位最高项，不等待页面识别或跨页探查；这个低置信预览不自动写 Map，也不降低批量确认阈值。当前 DOM 完全没有语义匹配时才进入显式路由或安全探查。

## 明确不改

- 不把页面当成 SURFACE，也不把页面加入映射分母。
- 不要求 Markdown 按 PAGE 章节组织，也不把功能节点改写成页面点击步骤。
- 不根据标题、路由、数组顺序或 DOM 自动生成 parentPageId。
- 不迁移或改写现有项目 JSON；旧投影继续兼容读取。
- 不改变关系节点、模块公共约束或 Map 的持久化口径。
- 不向 Map 增加 `pageId`，不允许在映射时顺带纠正 JSON 的页面归组；现有 `URL + selector + fingerprint` 仍是人工确认的 DOM 关联事实。
- 不新增“绑定锁定”、页面覆盖、自动跟随开关或浏览/选择多阶段模式；纠错只复用“保留左侧节点 → 浏览中间页面 → 在页面上选择位置/重新关联 → 点击 DOM”。
- 不新增“已审查”、通过/不通过、逐项打勾或强制完成状态；内容无问题且没有待保存操作时，PM 可以零操作进入下一页或结束。

## 否决方案

- “页面 → 模块 → 节点”：仍把正交的语义归属塞回导航路径。
- 把左侧降级为纯页面目录或异常补漏：Spec 不可能全部自动关联，左侧必须保留确认候选、手动选择和拖拽绑定。
- 根据标题、routeHints 或数组顺序猜页面父子：会把交互猜测伪装成产品事实。
- 只交换视觉层级、不补合同：无法稳定生成多级页面，也无法支持页面跨模块。
- 左侧跟随中间当前页自动展开、切换或滚动：会在用户查找正确 DOM 时夺走正在处理的 Spec 上下文，使错误自动候选无法被人工纠正。
- 为避免联动而增加绑定锁定条、页面覆盖和多阶段模式：状态过多，纠错成本高于直接保留左侧选中。

## 回归检查

- 新全局页面、旧 module.pages、显式多级父子、同页跨模块均能展示。
- 缺失父级、自引用、循环引用和重复页面 ID 被契约拒绝。
- 左侧页面导航可单向驱动中间页面；中间页面导航不改变左侧展开、选中和滚动；页面行只有总进度，搜索、模块筛选、待映射和按需出现的需复核筛选正确。
- 保留一个节点后在中间切换页面，仍能直接启动现有页面点选并保存新 Map；后续点击优先定位人工 Map。
- 点击、候选定位、拖拽、批量确认与完成率继续只作用于 SURFACE / ACTION。
- 切换页面前等待中的 Map 安全保存；没有修改时无需额外结束动作。
