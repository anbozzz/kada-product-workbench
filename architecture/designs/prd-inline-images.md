## 1. 结论与适用性

新增读取本地图片和配置视图字段，涉及文件访问边界，采用范围受限的图片快照方案。图片随既有 PRD 配置传递，不开放通用文件读取接口。

## 2. 目标、范围与依据

### 2.1 必须实现的结果

正文原位置显示真实图片，右下角支持等比例拖拽缩放；可放大查看，外层抽屉收窄时不溢出。

### 2.2 范围内

- PRD 内联及引用式 Markdown 图片、图片失败提示、运行态缩放、既有只读导出链。

### 2.3 明确不改

- 不修改 PRD、图片原件、两类 Map；不改三栏/评审模式、目录、搜索、Mermaid、绑定与导出入口。

### 2.4 当前事实与证据

- MDT 图片位于 PRD 的同项目相邻目录，由相对路径引用；现有渲染器主动输出文字占位。
- 两张会诊截图虽以 .png 命名，实际为 JPEG；以受支持位图的字节签名决定 MIME，不改名或转存来源文件。
- 只读 ZIP 的 Node 和 Windows 查看器均读取 data/config.json，可复用该链携带图片快照。

### 2.5 Unknown / TBD

- 无阻断项；外部网络图片不自动请求，显示明确提示。

## 3. 架构驱动因素

### 3.1 业务不变量与硬约束

- Markdown 和图片原件仍是来源；配置内图片为只读、非持久化快照。
- 仅读取 Markdown 实际引用、相对路径解析后仍在所选 Project 内的常见位图，拒绝绝对路径、网络、越界及符号链接逃逸。
- 单图最多 8 MiB，单文档最多 24 MiB，最多 100 个不同引用；错误逐图展示，不阻断其他正文。

### 3.2 质量场景

| ID | 来源（Source） | 刺激（Stimulus） | 环境（Environment） | 对象（Artifact） | 响应（Response） | 响应指标（Response Measure） |
|---|---|---|---|---|---|---|
| QA-01 | 用户 | 拖动图片及外层抽屉 | 绑定/评审模式 | 图片组件 | 等比例适配 | 图片实际宽度增减且不超正文宽度 |
| QA-02 | 文件边界 | 越界/伪装文件/缺失图 | 本地工作台 | 图片读取器 | 拒绝或逐图提示 | 禁止字节不进入配置，PRD 仍可读 |
| QA-03 | 交付闭环 | 导出并离线打开 | ZIP 查看器 | 图片快照 | 保留可显示图片 | 无源目录、无新增读取或写入接口 |

## 4. 整体设计

### 4.1 领域与所有权

PRD 解析仍归 prd-service；prd-images 只读取已绑定文档引用的图片；review-session 将图片快照加入视图。显示宽度只归前端组件，不写产品文件。

### 4.2 静态结构

review-session → prd-images → Markdown AST 与受限文件读取；PrdBrowser → PrdImage；review-package 复用已有配置冻结，不依赖本机资源接口。

### 4.3 运行交互

确认/恢复来源 → 解析 Markdown 图片及引用定义 → realpath 校验 Project 边界 → 限额和位图签名校验 → data URL 快照/逐图错误 → 原位置显示。重复路径去重；无外部请求、重试写入或补偿。

### 4.4 状态与数据

新增可选 images 字典，键为 Markdown 图片 URL，值为 data URL 或错误文本；imageDefinitions 保存图片引用定义，使仅显示绑定章节时仍可解析定义在其他章节的图片。源 Markdown/revision 不变；旧配置缺此字段时显示兼容提示。缩放随组件生命周期，无数据库迁移。导出时两类 Map 的本机来源路径均脱敏，图片快照原样冻结。

### 4.5 部署与运维

沿用本地服务、前端构建和 ZIP/Windows 查看器。依赖显式写入根 package.json；限额限制内存增长。重开来源刷新图片快照。

## 5. 候选方案与取舍

| 候选 | 收益 | 代价与风险 | 是否采用及原因 |
|---|---|---|---|
| 配置内受限位图快照 | 无新接口；现有离线链自动保留 | 配置增大，需要限额 | 采用，满足当前截图使用规模 |
| 直接 img 相对路径 | 前端改动少 | 错误基准目录，项目兄弟目录不可达，离线丢失 | 不采用 |
| 通用图片路径 HTTP 接口 | 可按需读取大文件 | 扩大文件暴露面，Node/Windows 导出需另建适配 | 本次不采用 |

## 6. 实施、迁移与回滚

1. 增加受限图片读取与定向测试，装配可选字段；图片组件替换文字占位；验证导出与完整工作台回归。
- 兼容与迁移：无项目文件迁移；只读包携带快照，旧包不被改写。
- 回滚点：移除可选字段及图片组件即可回到占位，不影响映射和产品正文。

## 8. 决定、风险与后续

- 验证结果：统一验证通过；真实 MDT 的 6 张图片均成功解码，院前时间轴原图为 499 × 1080，实际拖拽宽度从 276 → 348 → 288，显示比例不变；放大后关闭仍回到原 PRD。原 Spec 工作台、目录、搜索、绑定与只读 ZIP 由既有浏览器及服务测试覆盖。
- ADR：无，范围内决定集中在本设计；不改系统级持久化和事实源。
- RFC：不适用，当前根 Agent 可完成取舍。
- 残余风险与技术债：超限文件、SVG 及外部图片保留提示；不执行主动格式转换或远程下载。
- 后续触发条件：大量高清图/矢量图成为刚需时再评估独立资源打包与懒加载，不放宽目录边界。
