# 图形表达

先明确图要帮助用户判断什么，读取当前想法、PRD 或直接证据，保留未决分支的确定程度。选用最合适的图形类型，不要求用户会写 Mermaid 或指定绘图工具。

- 图属于当前 PRD 时，按 [product-documentation](../product-documentation/SKILL.md) 在对应章节使用 Mermaid 或既有图片机制；工作台已经能显示 Mermaid。正文拥有业务含义，图与对应正文一起核对，不另建需求事实源。
- 用户要求独立、精细图形时，完整读取 [原始图形方法](UPSTREAM-SKILL.md)，再按需读取其中的图形类型参考并使用随包 `assets/`、`scripts/`。原文件保留第三方规则和示例，其路径均相对于本 Skill 目录。生成内容用中文表达；原始英文参考和许可保留。
- 当前图过复杂时按语义拆为总览与细节，保留分支、角色和先后关系；视觉精简不能改变产品意思。

HTML 图形交付沿插件当前 HTML 完成协议；非产品图形如实说明 PRD／Spec 不适用。只在 Markdown 中添加 Mermaid 时不把它当作本地 HTML 交付。
