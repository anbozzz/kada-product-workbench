# PC 业务页面

Ant Design 提供表格、表单、菜单、弹窗等网页组件。已有页面体系优先；起步样例采用 React 18.3.1、antd 5.27.5、esbuild 0.25.12，版本已固定用于重复构建。升级时核对官方文档、兼容性及样例，不追随 latest 自动漂移。

- 按产品任务组织导航、筛选、列表、详情与操作，保留页面之间的返回关系。组件默认值不替代页面设计。
- 中文表格考虑长文本、列宽、空数据、筛选重置、分页和行操作；真正宽的数据区可局部滚动，整个页面不应意外横向溢出。
- 使用 `ConfigProvider` 设置主题与中文语言；组件主题、字号和间距与已采纳视觉方案一致。
- 表单有明确标签和校验反馈；主操作可用键盘到达，加载与禁用防止误操作。弹窗关闭后保留必要上下文。
- 验证目标 PC 视口及较窄窗口，检查焦点、弹层、长内容、滚动和主路径。模板是可替换的基础，不能用完成模板操作冒充用户功能验收。

来源：[Ant Design React](https://ant.design/docs/react/introduce/)、[主题](https://ant.design/docs/react/customize-theme/)、[组件](https://ant.design/components/overview/)。包内代码原创；使用的依赖按各自许可证分发。页面依赖属于目标 Project，工作台本身不引入 antd。
