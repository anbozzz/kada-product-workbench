# 审问与想法澄清

沿当前想法的决策分支逐项追问，直到与用户形成共同理解。每次只提出一个问题，附推荐答案及理由，等待用户回答后再继续。决策属于用户；能从已有材料或环境查到的事实先自行核实。

从目标用户、真实问题和成功结果开始，沿场景检查范围、流程、角色、例外和取舍；只追问当前有意义的分支。把已回答的问题、决定和待确认项保留在当前任务中，避免重复询问。用户明确表示已达成共同理解后，按已授权范围接续；需要形成 PRD 时使用同包 [product-documentation](../product-documentation/SKILL.md)。

不得把推荐答案、用户暂未回答或讨论结束自动写成产品确认。用户调整深度、结束追问或明确要求先出草稿时，以当前指令为准。
